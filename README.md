# Malyika Portfolio

A modern full-stack portfolio website built using:
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Features
- Responsive Design
- Contact Form with MongoDB
- Graphic Design Gallery
- Download CV
- GitHub & LinkedIn Integration
